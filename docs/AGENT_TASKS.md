### الفيزياء المعتمدة
- **`g = 10 m/s²`** في كل مكان (دفتر البيان يستخدمه في مسائله، ص44–52). لا تستخدم 9.8 أو 9.81.
- **السعة الزاوية الصغيرة: `θ_max ≤ 0.24 rad` (≈14°)** (ص40). فيها `sinθ ≈ θ` والحركة جيبية.
- السعة الكبيرة (البسيط والمركب): الحركة **اهتزازية غير جيبية** ويُعطى الدور بالعلاقة `T′ ≈ T₀(1 + θ_max²/16)` (ص41، `θ_max` بالراديان).
- كل النواسات تُترك **دون سرعة ابتدائية** من الوضع الأقصى: `θ(0)=θ_max` أو `x(0)=+X_max`.
- كل المقادير بوحدات SI، والواجهة تعرض الوحدة بجانب كل قيمة.

### قواعد الرسم (من `docs/PHYSICS_AND_DESIGN.md` وتُلزم هنا)
- **كل سهم قوة يُرسم في إحداثيات المشهد العالمية** (غير ابن لمجموعة تدور). اتجاهه يُحسب من الفيزياء، لا من دوران العنصر الأب.
- طول السهم متناسب مع شدة القوة بمقياس ثابت، ويُخفى السهم إذا قلّت الشدة عن العتبة (لا سهم بطول صفر).
- داخل الرسم **رموز قصيرة فقط** (`w`, `F_s`, `T`, `R`, `x`, `x₀`, `θ`, `d`, `c`, `O`, `Δ`). الأسماء العربية والقوانين في اللوحات الجانبية (HTML) لا داخل المشهد.
- لا تتداخل التسميات مع الأسهم أو الأجسام. زر «إخفاء القوى» يخفي الأسهم **وتسمياتها** معاً، ولا يخفي أسماء الأجزاء ولا خط التوازن.
- لا يُوصف أي شيء في الواجهة بـ«واقعي» أو «نهائي».
- **لا مقاييس مقصوصة (clamp) تُخفي أثر المنزلقات:** تغيير أي منزلق يغيّر الهندسة خطياً بالمتر.

### الزمن
- استخدم الزمن الفعلي: `THREE.Clock`، و`dt = Math.min(clock.getDelta(), 0.05)`. **ممنوع** `time += 0.016` لكل إطار (يسرّع المحاكاة على شاشات 120/144Hz).
- لكل نواس **ساعته الخاصة `t`**. عند تغيير أي منزلق خاص به أو زر «إعادة الضبط» تعود `t=0` ويبدأ من الوضع الأقصى دون سرعة ابتدائية.
- «إيقاف مؤقت» يوقف الزمن ولا يعيد الضبط.

## المهمة 1 — وحدة الفيزياء والاختبارات (`src/physics.js`)

اكتب دوالاً نقية (تُصدَّر كلها) وغطّها باختبارات:

```js
export const G = 10;
export const SMALL_ANGLE = 0.24;                  // rad

// المرن
springOmega0(m,k) = √(k/m);  springT0(m,k) = 2π√(m/k);  springX0(m,k) = m*G/k;

// الفتل
rodInertiaCenter(M,L) = M*L*L/12;                 // ساق حول منتصفها
torsionInertia({M,L,m,r}) = M*L*L/12 + 2*m*r*r;   // ساق + كتلتان نقطيتان متناظرتان
torsionOmega0(k,I) = √(k/I);  torsionT0(k,I) = 2π√(I/k);

// البسيط
simpleOmega0(L,g) = √(g/L);  simpleT0(L,g) = 2π√(L/g);

// المركب: ساق متجانسة (M, ℓ) والمحور عند مسافة s_O=f·ℓ من طرفها العلوي،
// وكتلة نقطية اختيارية m′ عند الطرف السفلي.
compoundProps({M,l,f,mp}) → { m, d, I, omega0, T0, Leq }
//   y_rod = l/2 − f·l ,  y_end = l − f·l   (بعد نازل من O)
//   m = M+mp ;  d = (M·y_rod + mp·y_end)/m
//   I = M·l²/12 + M·y_rod² + mp·y_end²
//   ω0 = √(m·G·d/I) ;  T0 = 2π√(I/(m·G·d)) ;  Leq = I/(m·d)   // طول النواس البسيط المواقت

largeAmplitudePeriod(T0, thetaMax) = T0*(1 + thetaMax**2/16);   // علاقة الدفتر ص41
stepPendulumRK4(state{theta,omega}, omega0Sq, dt) → state       // θ″ = −ω0² sinθ
compoundReaction({m,d,theta,omega,alpha}) → {Rx,Ry}
//   r̈ = d·α·(cosθ, sinθ) + d·ω²·(−sinθ, cosθ) ;  R = m·r̈ + (0, m·G)   (y لأعلى)
```

### متجهات اختبار إلزامية (تسامح نسبي `1e-3` ما لم يُذكر غيره)
| الحالة | القيم المتوقعة |
|---|---|
| مرن: m=0.5, k=20 | x₀=0.25 ، ω₀=6.3246 ، T₀=0.99346 |
| فتل: M=0.20, L=0.40, m=0.05, r=0.15, k=0.06 | I_rod=2.6667e-3 ، I_Δ=4.9167e-3 ، ω₀=3.4933 ، T₀=1.7986 |
| بسيط: L=1.6, g=10 | T₀=2.5133 ؛ L=1 ⇒ T₀=1.9869 (≈ «نواس يدق الثانية» ص41) |
| بسيط سعة 60°: L=1.6 | علاقة الدفتر ⇒ T′=2.6855 ؛ التكامل العددي RK4 يجب أن يطابق الدور الدقيق **2.6972** بتسامح 0.5% |
| مركب A: M=0.5, ℓ=0.8, f=0.1, m′=0 | d=0.32 ، I=0.077867 ، T₀=1.3861 ، Leq=0.48667 |
| مركب B: نفس A مع m′=0.2 | m=0.7 ، d=0.434286 ، I=0.181547 ، T₀=1.53546 ، Leq=0.59719 |

وأضف اختباراً يتحقق أن `Leq` يعطي `simpleT0(Leq, G) == T₀` للمركب، وأن RK4 يحفظ الطاقة (انحراف < 1e-4 على 10 دورات).

## المهمة 3 — النواس المرن (`src/scene/spring.js`)

**المرجع:** ص7 (الرسم الأيمن: حالة السكون وحالة الحركة، المسطرة المدرّجة، `x₀`, `X_max`, `w`, `F_s`, `F`) وص8.

### المعاملات
| الرمز | المجال | الافتراضي |
|---|---|---|
| m (kg) | 0.1 → 1.0 ، خطوة 0.05 | 0.5 |
| k (N/m) | 10 → 100 ، خطوة 1 | 20 |
| X_max (m) | 0.02 → 0.15 ، خطوة 0.01 | 0.08 |

الطول الطبيعي `L0 = 0.30 m` ثابت. المقياس البصري `S = 3` وحدة/متر، **خطي بلا أي clamp**.

### الفيزياء (محور x نحو الأسفل، الصفر عند التوازن O)
```
x₀ = m g / k ;   x(t) = X_max cos(ω₀ t) ;   v = −ω₀ X_max sin(ω₀ t) ;   a = −ω₀² x
F_s = k (x₀ + x) ;   F (الإرجاع) = −k x ;   w = m g
E_k = ½ m v² ;  E_p = ½ k x² ;  E = ½ k X_max²   (ثابتة)
```

### الهندسة
1. حامل علوي ثابت (عارضة) عند `y_top`. النابض **حلزوني حقيقي** (`TubeGeometry`): عدد اللفات ثابت `N=14`، نصف قطر اللفة 0.16، نصف قطر السلك 0.014، **طوله = المسافة من الحامل إلى أعلى الجسم** يتغير مع x بالمقياس S. (تحقق برمجياً أن `pitch ≥ 2.2×نصف قطر السلك` في كل الحالات.)
2. الجسم كرة معدنية بخطاطيف وقطرها يزيد قليلاً مع m (من 0.12 إلى 0.2). **مركز الجسم هو نقطة القياس**: `y_c(t) = y_O − S·x(t)` حيث `y_O = y_top − S(L0 + x₀) − r_body`.
3. **خط التوازن O**: خط أفقي متقطع رمادي بمستوى `y_O` عبر الرسم كله، مع التسمية `O`.
4. **المسطرة**: جانبية، صفرها عند O، تدرج كل 1 cm، ترقيم كل 5 cm، موجبة نحو الأسفل، وتمتد `±(X_max+0.03)`، مع علامتي `X_max` على الطرفين.
5. **الظل الشبحي**: علامة (خط قصير) عند موضع الطرف السفلي للنابض بطوله الطبيعي، وخط قياس `x₀` بينها وبين موضع التعليق في التوازن (شبه شفاف).
6. خط قياس `x` من O إلى مركز الجسم الحالي (يُخفى إذا |x|<0.003).

### الأسهم (عالمية، تبدأ من مركز الجسم بإزاحة أفقية)
| السهم | الاتجاه | الطول |
|---|---|---|
| `w` | نحو الأسفل دائماً | `0.12 × mg` |
| `F_s` | نحو الأعلى دائماً | `0.12 × k(x₀+x)` |
| `F = −kx` | نحو O: **ينعكس** حسب إشارة x | `0.12 × k|x|` |

`F` وردي ويُرسم عند الجهة المقابلة للمسطرة. التسميات: `w`, `Fₛ`, `F`.

### قبول
- `x` المعروض يساوي الإزاحة المرئية فعلاً: عند `t=0` يكون مركز الجسم تحت O بمقدار `S·X_max` بدقة 1e-6.
- سهم `F` يشير إلى الأعلى عندما x>0 وإلى الأسفل عندما x<0 (اختبر في 4 لحظات).
- تغيير m أو k يغيّر موضع O وطول الظل `x₀`؛ وتغيير X_max يغيّر مدى الحركة خطياً. لا قصّ عند أي قيمة في المجال.
- `F_s − w = F` (الفرق بين طولي السهمين الشاقوليين) في كل إطار.
- لا تسمية تتداخل مع سهم في العرض الأمامي بالأبعاد الافتراضية (فحص بصري).

## المهمة 4 — نواس الفتل (`src/scene/torsion.js`)

**المرجع:** ص28 (الشكل: إطار حامل، سلك شاقولي على المحور Δ، ساق أفقية معلّقة من منتصفها، `T` للأعلى، `w` للأسفل، ومزدوجة فتل `F` و`−F`، والزاوية θ) وص29 (عزم العطالة).

### المعاملات
| الرمز | المجال | الافتراضي |
|---|---|---|
| M كتلة الساق (kg) | 0.05 → 0.5 | 0.20 |
| L طول الساق (m) | 0.2 → 0.6 | 0.40 |
| m كتلة كل كتلة نقطية (kg) | 0 → 0.2 | 0.05 |
| r بعد الكتلتين عن السلك (m) | 0.02 → L/2 | 0.15 |
| k ثابت الفتل (N·m/rad) | 0.01 → 0.10 | 0.06 |
| θ_max (rad) | 0.1 → 1.2 | 0.6 |

(المنزلق `r` يُقيَّد ديناميكياً بـ`L/2`. **احذف منزلق «عزم العطالة» المستقل**: عزم العطالة يُحسب من الهندسة.)

### الفيزياء
```
I_Δ = M L²/12 + 2 m r² ;   ω₀ = √(k/I_Δ) ;   T₀ = 2π√(I_Δ/k)    (لا تتعلق بالسعة)
θ(t) = θ_max cos(ω₀ t) ;   θ̇ = −ω₀ θ_max sin(ω₀ t) ;   θ̈ = −ω₀² θ
Γ = −k θ   (عزم الإرجاع) ;   E_p = ½ k θ² ;  E_k = ½ I_Δ θ̇²
```

### الهندسة (المقياس `S = 4` وحدة/متر)
1. **إطار حامل**: قاعدة، عمودان شاقوليان، عارضة علوية تتصل بهما (حالياً الحامل العلوي معلّق في الفراغ بلا إطار، وهذا خطأ).
2. سلك شاقولي رفيع من منتصف العارضة إلى منتصف الساق، ومشبكان عند الطرفين. **المحور Δ**: خط شاقولي متقطع بنقطة وشرطة يمتد على السلك مع التسمية `Δ`.
3. ساق أفقية تدور حول Δ في **مستوى أفقي** (`rotation.y = θ`، والموجب عكس عقارب الساعة من الأعلى). على الساق الكتلتان النقطيتان (كرتان) عند `±r·S`، ونصف القطر ∝ ∛m.
4. **قرص تدريج ثابت** تحت الساق (حلقة بتدريج كل 10° وعلامة الصفر على +x). هو **خط التوازن الزاوي θ=0**. استبدل الخط الشاقولي الحالي له.
5. مؤشر على طرف الساق وقوس `θ` على القرص من علامة الصفر إلى المؤشر، مع التسمية `θ`.

### الأسهم
- `T` للأعلى و`w` للأسفل: عالميان، على امتداد Δ عند مركز الساق بإزاحة أفقية صغيرة 0.12، **متساويا الطول** بمقياس `0.12×(M+2m)g`. (عزماهما حول Δ معدومان، كما في الدفتر.)
- عزم الإرجاع `Γ = −kθ`: **سهم قوسي** حول Δ على ارتفاع 0.5 فوق الساق، **اتجاهه عكس θ**، وامتداده الزاوي ∝ |Γ|/(k θ_max) حتى 120°. يُخفى إذا |θ|<0.01. والتسمية `Γ`.

### قبول
- تغيير M أو L أو m أو r يغيّر I_Δ المعروض والدور T₀ **والهندسة** معاً؛ وT₀ لا يتغير بتغيير θ_max.
- القيم الافتراضية تعطي T₀=1.7986 s (ويقاس بالزمن الفعلي ضمن 0.5%).
- لا يوجد أي سهم خطي أفقي منفصل (السهم القديم محذوف).
- إشارة Γ دوماً عكس إشارة θ (اختبر في 4 لحظات).
- الإطار يصل الحامل بالقاعدة، ولا جزء معلّق في الفراغ.

## المهمة 5 — النواس الثقلي البسيط (`src/scene/simple.js`)

**المرجع:** ص41 (الشكل السفلي: الشاقول، الخيط `l`، الزاوية θ، `T`، `w`، المماس والناظم، ومركبة الثقل `w sinθ`) وص42 (الاشتقاق) وص46–47 (مسائل، `g=10`، `T = m(g + v²/L)` عند الشاقول).

### المعاملات
| الرمز | المجال | الافتراضي |
|---|---|---|
| L (m) | 0.2 → 2.0 ، خطوة 0.05 | 1.0 |
| m (kg) | 0.05 → 0.5 | 0.10 |
| g (m/s²) | 1.6 → 15 | **10** |
| θ_max (rad) | 0.05 → 1.05 (≈60°) ، خطوة 0.01 | 0.20 |

### الفيزياء
```
ω₀ = √(g/L) ;  T₀ = 2π√(L/g)              (سعات صغيرة)
θ_max ≤ 0.24 :  θ(t) = θ_max cos(ω₀ t) ،  θ̇ = −ω₀θ_max sin(ω₀t)
θ_max  > 0.24 :  تكامل RK4 للمعادلة θ″ = −(g/L) sinθ ، وتُعرض شارة «سعة كبيرة: الحركة غير جيبية»،
                 والدور المعروض T′ = T₀(1 + θ_max²/16)
T (التوتر) = m ( g cosθ + L θ̇² )    w_t = m g sinθ    w_n = m g cosθ
```

### الهندسة (المقياس `S = 1.5` وحدة/متر، خطي بلا حدّ أعلى)
1. حامل علوي وكتلة تثبيت عند O. **الخيط يبدأ من O بالضبط وينتهي عند مركز الكرة** بطول `S·L` (احسب موضعي الطرفين وولّد الأسطوانة بينهما، ولا تستخدم `scale.y` على أسطوانة ثابتة المركز كما في الكود الحالي، فهو يفصل الخيط عن O ويتجاوزها عند قيم L بعيدة عن 2.44).
2. الكرة نصف قطرها ثابت **0.12** (صغير نسبةً إلى الطول، كما يشترط الدفتر ص41).
3. **الشاقول** من O: خط متقطع رمادي (خط التوازن). **المسار**: قوس متقطع بلون مختلف نصف قطره `S·L` بين `−θ_max` و`+θ_max`. قوس `θ` عند O بين الشاقول والخيط مع التسمية `θ`.
4. الدوران بحساب الإحداثيات: موضع الكرة `(S L sinθ, −S L cosθ)` نسبةً إلى O، والخيط ينتج من الموضع لا من تدوير مجموعة أبناء.

### الأسهم (عالمية، تبدأ من مركز الكرة؛ المقياس نسبي إلى mg بحيث طول `w` = 1.0 دائماً)
| السهم | الاتجاه |
|---|---|
| `w` | شاقولي نحو الأسفل **دائماً** (لا يميل مع الخيط) |
| `T` | على الخيط نحو O ، طوله `T/(mg)` |
| `w_t = mg sinθ` | مماسي، نحو الشاقول (متقطع رفيع) |
| `w_n = mg cosθ` | على امتداد الخيط نحو الخارج (متقطع رفيع) |

التسميات: `w`, `T`, `wₜ` , `wₙ`. وتُخفى مع زر القوى.

### قبول
- الاختبار على `window.__lab`: اتجاه سهم `w` العالمي = `(0,−1,0)` في كل إطار، واتجاه `T` = `normalize(O − ballPos)` بدقة 1e-6.
- المسافة بين طرف الخيط العلوي و O تساوي 0 (تسامح 1e-6) لكل قيمة L في المجال، ومسافة الطرف السفلي إلى مركز الكرة تساوي 0.
- طول الخيط المرئي ∝ L خطياً من 0.2 إلى 2.0 بلا تشبّع.
- عند θ_max=1.05 ، L=1.6 ، g=10 تُعرض `T′=2.6855 s`، وتُقاس الفترة الفعلية في المحاكاة ≈ 2.697 s (تسامح 1%).
- عند θ=0 ينطبق الخيط على الشاقول وتصبح `w_t=0` (السهم مخفي) وتعطي القيم `T = m(g + L θ̇²)`.

## المهمة 6 — النواس الثقلي المركب (`src/scene/compound.js`)

**المرجع:** ص40 (الشكل: جسم صلب، المحور Δ عند O، مركز العطالة c، المسافة d، الزاوية θ، `w` عند c، `R` عند O، ذراع العزم `d sinθ`) وص42 (الدور) وص45، 48–53 (مسائل: ساق وكتل نقطية، حلقة، قرص).

### النموذج
ساق متجانسة (M, ℓ) محورها الأفقي Δ عند O على بعد `f·ℓ` من طرفها العلوي، وكتلة نقطية اختيارية `m′` عند طرفها السفلي. (هذا النموذج هو ما تستخدمه مسائل الدفتر: «ساق مثبتة من نقطة وفي طرفها كتلة».)

### المعاملات
| الرمز | المجال | الافتراضي |
|---|---|---|
| M (kg) | 0.1 → 1.0 | 0.5 |
| ℓ (m) | 0.3 → 1.0 | 0.8 |
| f (موضع المحور كنسبة من ℓ) | 0.05 → 0.45 | 0.10 |
| m′ (kg) | 0 → 0.5 | 0 |
| θ_max (rad) | 0.05 → 1.05 | 0.20 |

### الفيزياء (كل الصيغ في `compoundProps` بالمهمة 1)
```
d = Oc ;  I_Δ ;  ω₀ = √(m g d / I_Δ) ;  T₀ = 2π√(I_Δ/(m g d)) ;  Leq = I_Δ/(m d)
θ″ = −(m g d / I_Δ) sinθ        (الصيغة العامة، ص40)
Γ_w = −m g d sinθ                (عزم الثقل حول O)
θ_max ≤ 0.24 : حل جيبي    وإلا RK4 + شارة السعة الكبيرة + T′ = T₀(1+θ_max²/16)
R = m·r̈ + (0, m g)                (دالة compoundReaction)
```

### الهندسة (المقياس `S = 2.2` وحدة/متر)
1. حامل علوي ومحور أفقي حقيقي (أسطوانة على `z`) عند O، يمر عبر ثقب في الساق.
2. الساق شريط مسطح (عرض 0.09 وسماكة 0.05) يمتد من `−(f ℓ)` إلى `+(1−f)ℓ` على طول محوره **الذي ينزل من O** (فلا يمتد أي جزء فوق المحور إلا إذا كان f<0 وهذا غير مسموح، والكود الحالي يمدّ الساق فوق المحور بنحو 1.2 وحدة وهذا خطأ). الكتلة `m′` كرة/أسطوانة ملتصقة بالطرف السفلي **دائماً** (لا تُزاح عنه كما يفعل `mass.position.y = −2.8`).
3. **مركز العطالة c**: كرة حمراء صغيرة تُوضع على المحور عند المسافة المحسوبة `d` من O (لا عند قيمة ثابتة)، مع التسمية `c`. خط قياس `d` بين O و c بإزاحة جانبية.
4. **الشاقول** من O متقطع (خط التوازن). قوس `θ` عند O. **ذراع العزم**: قطعة أفقية متقطعة من الشاقول حتى c بطول `d sinθ` وتسميتها `d sinθ`.
5. وضع الدوران: موضع c = `O + S·d·(sinθ, −cosθ)`، ويُدار الجسم كله بـ`rotation.z = θ` (الموجب نحو +x كما في الدفتر).

### الأسهم (عالمية، المقياس نسبي إلى mg؛ طول `w` = 1.0)
| السهم | موضع الابتداء | الاتجاه |
|---|---|---|
| `w` | عند c | شاقولي نحو الأسفل (لا يدور) |
| `R` | عند O | ناتج `compoundReaction` (أخضر) |

### قبول
- مع القيم الافتراضية: `d=0.32` و`T₀=1.3861 s` و`Leq=0.4867 m`؛ ومع `m′=0.2`: `d=0.434286` و`T₀=1.5355 s`.
- موضع علامة c المرسومة يطابق `d` المحسوب بدقة 1e-6، ويتحرك عند تغيير f أو m′ أو M.
- سهم `w` اتجاهه العالمي `(0,−1,0)` في كل إطار (والكود الحالي يرسمه إلى الأعلى).
- لا جزء من الساق فوق المحور، والكتلة `m′` لا تنفصل عن الساق.
- قيمة الدور المقيسة بالزمن الفعلي تطابق `T₀` ضمن 0.5% للسعات الصغيرة.
