# الفيزياء والتصميم في مختبر النواسات

هذه الوثيقة تصف النماذج الموجودة في التطبيق ونتائج التحقق التي نُفذت. المرجع الأساسي هو صور الصفحات المطلوبة من **دفتر البيان في الفيزياء**؛ استُخدمت صور الصفحات لا النص المستخرج. استُخدمت النوطة الشاملة للمقارنة فقط عند الحاجة.

## الاصطلاحات والثوابت

| الرمز | المعنى | الوحدة |
|---|---|---|
| `w` | قوة الثقل، `mg` | N |
| `k` | صلابة النابض أو ثابت الفتل بحسب النموذج | N/m أو N·m/rad |
| `x`, `X_max`, `x₀` | الإزاحة، السعة الخطية، والاستطالة السكونية | m |
| `θ`, `θ_max` | الإزاحة الزاوية والسعة الزاوية | rad |
| `I_Δ` | عزم العطالة حول المحور `Δ` | kg·m² |
| `c` | مركز العطالة | — |
| `d` | المسافة بين `O` و`c` | m |
| `R` | رد فعل المحور | N |
| `F_s`, `T` | توتر النابض، وشد الخيط | N |
| `Γ` | عزم الإرجاع | N·m |
| `ω₀`, `T₀` | النبض والدور الخاصان | rad/s, s |

ألوان المشهد مأخوذة من `src/scene/common.js`: الثقل برتقالي `#d97706`، والتوتر أزرق `#0284c7`، والإرجاع وردي `#db2777`، ورد الفعل أخضر `#16a34a`، وخط التوازن رمادي `#64748b`، والمسار `#94a3b8`.

- يستخدم التطبيق `g = 10 m/s²`.
- حد الزاوية الصغيرة هو `θ_max ≤ 0.24 rad`. في البسيط والمركب تُستخدم الحركة التوافقية عند هذا الحد، والتكامل العددي عند السعات الأكبر.
- تقريب الدور للسعة الكبيرة في البسيط والمركب هو `T′ = T₀(1 + θ_max²/16)`.
- تُترك النواسات من السكون عند مطالها الأقصى. القيم المعروضة ناتجة عن النموذج نفسه، ووحداتها ظاهرة بجوارها.
- الأسهم متجهات في إحداثيات العالم، مستقلة عن دوران الجسم. تُخفى الأسهم القصيرة تحت حد مرئي أدنى، ويخفي زر القوى الأسهم وتسمياتها معًا.
- الزمن مصدره `THREE.Clock`، وتُحد `dt` عند `0.05 s`. لكل نواس زمنه الخاص؛ تغيير منزلقه يعيد زمنه إلى الصفر، والإيقاف المؤقت لا يعيد الزمن.

## النواس المرن

المعاملات الافتراضية هي `m = 0.5 kg` و`k = 20 N/m` و`X_max = 0.08 m`. يتحرك الجسم وفق:

```text
x₀ = mg/k                 ω₀ = √(k/m)               T₀ = 2π√(m/k)
x(t) = X_max cos(ω₀t)    v(t) = −ω₀X_max sin(ω₀t)
a = −ω₀²x                F = −kx                   F_s = k(x₀ + x)
Eₖ = ½mv²                Eₚ = ½kx²                 E = Eₖ + Eₚ
```

يعرض المشهد نابضًا حلزونيًا، وخط التوازن، وقياسي `x₀` و`x`، وسهمي الثقل والإرجاع، ومسطرة السعة. طول النابض المرئي يتغير مع `x₀+x` ومعامل التحجيم الخطي. تبقى `F_s` موقعة وفق قانون هوك؛ عند الانضغاط قد ينعكس اتجاه سهمها. هذا التعارض مع عبارة «السهم للأعلى دائمًا» موثق في [المسائل المفتوحة](./OPEN_QUESTIONS.md).

## نواس الفتل

المعاملات الافتراضية هي `M = 0.2 kg` و`L = 0.4 m` وكتلة كل من الكتلتين الطرفيتين `m = 0.05 kg` على بعد `r = 0.15 m`، وثابت الفتل `k = 0.06 N·m/rad` وسعة `0.6 rad`.

```text
I_rod = ML²/12            I_Δ = ML²/12 + 2mr²
ω₀ = √(k/I_Δ)             T₀ = 2π√(I_Δ/k)
θ(t) = θ_max cos(ω₀t)     Γ = −kθ
Eₚ = ½kθ²                 Eₖ = ½I_Δθ̇²              E = Eₚ + Eₖ
```

يتغير عزم العطالة مع أبعاد الساق وموضع الكتل. يظهر الحامل والمحور `Δ`، والساق والكتلتان، وخط التوازن الزاوي، ومؤشر الزاوية وعزم الإرجاع. النموذج خطي التواؤم كما في علاقة الفتل المستخدمة؛ لا يُطبق عليه تقريب الدور للسعات الكبيرة الخاص بالنواسين الثقليين.

## النواس الثقلي البسيط

المعاملات الافتراضية هي `L = 1 m` و`m = 0.1 kg` و`g = 10 m/s²` و`θ_max = 0.2 rad`. المجال الزاوي `0.05–1.05 rad`.

```text
ω₀ = √(g/L)               T₀ = 2π√(L/g)
θ_max ≤ 0.24: θ = θ_max cos(ω₀t)
θ_max > 0.24: θ̈ = −(g/L)sinθ  (تكامل RK4)
T′ = T₀(1 + θ_max²/16)
T = m(g cosθ + Lθ̇²)      wₜ = −mg sinθ           wₙ = mg cosθ
```

يبدأ الخيط من `O` وينتهي بمركز الكرة، وطوله المرئي يتناسب خطيًا مع `L`. الكرة نصف قطرها ثابت. السهم `w` شاقولي دائمًا، و`T` على امتداد الخيط نحو `O`؛ مركبتا الثقل المماسية والعمودية تُرسمان منفصلتين.

## النواس الثقلي المركب

المعاملات الافتراضية هي ساق `M = 0.5 kg` و`ℓ = 0.8 m`، وموضع المحور `f = 0.1` من طولها، وكتلة طرفية `m′ = 0`، و`θ_max = 0.2 rad`. المجال الزاوي `0.05–1.05 rad`.

```text
y_rod = ℓ/2 − fℓ        y_end = ℓ − fℓ
m = M + m′              d = (M y_rod + m′y_end)/m
I_Δ = Mℓ²/12 + M y_rod² + m′y_end²
ω₀ = √(mgd/I_Δ)         T₀ = 2π√(I_Δ/(mgd))       L_eq = I_Δ/(md)
θ̈ = −(mgd/I_Δ)sinθ     Γ_w = −mgd sinθ
R = m r̈_c + (0, mg)
```

لـ`θ_max ≤ 0.24 rad` الحركة توافقية؛ خلاف ذلك تُكامل معادلة الحركة بطريقة RK4 ويُعرض تقريب `T′` أعلاه. يظهر المحور الأفقي `Δ`، والساق من `O` إلى أسفل فقط، والكتلة الطرفية الملتصقة عند وجودها، ومركز العطالة `c` عند بعده المحسوب `d`، وذراع العزم `d sinθ`. سهم `w` شاقولي عند `c`، وسهم `R` عند `O`.

## ملاحظات مرجعية وأسئلة مفتوحة

- في الصفحة 47 من دفتر البيان تظهر قيمة مطبوعة `2.673 s`. لا تتفق هذه القيمة مع إعادة الحساب المباشر للعلاقة والمدخلات كما تظهر في المسألة؛ سُجلت هنا كقيمة مطبوعة غير متوافقة، ولم تُستخدم لتغيير قانون المحاكاة.
- اختلاف سهم `F_s` عند انضغاط النابض، وفارق القيمة `2.6855 s` المطلوبة عن الحساب عند `θ_max = 1.05 rad` موضحان في [OPEN_QUESTIONS.md](./OPEN_QUESTIONS.md). الحساب المباشر للعلاقة عند `1.05 rad` يعطي نحو `2.68645 s`، بينما `2.6855 s` توافق تقريب السعة إلى `π/3`. التطبيق يستخدم قانون هوك الموقّع والعلاقة المحددة مع قيمة المنزلق الفعلية، دون تقريب المدخل.
