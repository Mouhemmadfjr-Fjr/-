# مختبر النواسات الأربعة

مشروع تفاعلي لعرض النواس المرن ونواس الفتل والنواس الثقلي البسيط والنواس الثقلي المركب، مع التحكم بالمعلمات وعرض القيم الفيزيائية.

## التوثيق

- [المرجع الفيزيائي وقواعد الرسومات وخطة التحقق](docs/PHYSICS_AND_DESIGN.md)

## التقنية
- Vite
- JavaScript
- Three.js
- GitHub Pages عبر GitHub Actions

## تنبيه
المشروع قيد التطوير والمراجعة العلمية والبصرية. لا تعتبر المعادلات أو الرسومات نهائية قبل اجتياز قائمة التحقق في ملف التوثيق.
