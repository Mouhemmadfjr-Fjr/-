# مختبر النواسات الأربعة

محاكاة تفاعلية بالنماذج ثلاثية الأبعاد للنواس المرن ونواس الفتل والنواس الثقلي البسيط والمركب. تتغير الرسومات والقيم اللحظية والعلاقات النظرية مع المعاملات، وتعرض القيم بوحدات SI.

## التشغيل والاختبار

يتطلب المشروع Node.js وnpm. من مجلد المشروع:

```sh
npm i
npm run dev
npm test
```

لإنشاء نسخة الإنتاج محليًا:

```sh
npm run build
```
